# 🚖 Ola Ride Insights – July 2024

An interactive data analytics project that explores Ola ride-booking data for July 2024. This project analyzes booking performance, revenue, cancellations, vehicle types, customer behavior, and ratings using Python, SQL, Streamlit, and Power BI.

## 📌 Project Overview

Ola Ride Insights transforms raw ride-booking data into meaningful business insights through interactive dashboards and data analysis.

The project focuses on understanding ride demand, identifying cancellation patterns, evaluating revenue performance, and analyzing customer and driver ratings.

## 🎯 Project Objectives

- Analyze overall ride-booking performance.
- Identify successful and unsuccessful bookings.
- Evaluate revenue and payment methods.
- Understand customer and driver cancellation patterns.
- Compare vehicle types based on performance.
- Analyze customer and driver ratings.
- Generate actionable business insights.

## ✨ Key Features

### 1. Executive Summary
- Total bookings and successful bookings.
- Revenue and quoted fare lost.
- Average ride distance.
- Booking status breakdown.
- Daily ride-booking trends.

### 2. Vehicle Analysis
- Vehicle type performance.
- Success rate by vehicle type.
- Average customer ratings.
- Top-performing vehicle by revenue.
- Revenue per kilometer.

### 3. Revenue Analysis
- Total revenue from successful rides.
- Average completed fare.
- Cash and digital payment share.
- Revenue by payment method.
- Top customers by booking value.

### 4. Cancellation Analysis
- Customer cancellation percentage.
- Driver cancellation percentage.
- Driver not found percentage.
- Driver-side share of failed bookings.
- Cancellation reasons and patterns.

### 5. Rating Analysis
- Average driver rating.
- Average customer rating.
- Lowest rating.
- Low-rating analysis.
- Customer and driver rating comparisons.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/yashtailor3009/Ola_Ride-Data-Analysis.git
```

### 2. Navigate to the Project Folder

```bash
cd Ola_Ride-Data-Analysis/ola_ride_insights
```

### 3. Create a Virtual Environment

```bash
python3 -m venv .venv
```

### 4. Activate the Environment

**macOS / Linux**

```bash
source .venv/bin/activate
```

**Windows**

```bash
.venv\Scripts\activate
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the Streamlit Application

```bash
streamlit run app.py
```

*Note: Make sure the required dataset and project files are available in their expected locations.*

## 💡 Key Insights

- Approximately 62.09% of bookings become successful rides.
- Driver-side issues account for a significant share of failed bookings.
- Successful rides generated approximately ₹3.51 crore in revenue.
- Approximately ₹2.15 crore represents quoted fare value from unsuccessful bookings.
- Cash payments account for 54.75% of successful bookings, while digital payments account for 45.25%.
