
# 🚖 Ola Ride Insights – July 2024

An end-to-end analytics project analyzing **103,024 Ola bookings** from July 2024 using Python, SQL, Streamlit, and Power BI.

The project explores booking performance, revenue, cancellations, vehicle performance, customer behavior, and ratings through interactive dashboards and business insights.

## 🎯 Project Objectives

- Analyze overall ride-booking performance.
- Identify successful and unsuccessful bookings.
- Evaluate revenue and payment methods.
- Understand customer and driver cancellation patterns.
- Compare vehicle types.
- Analyze customer and driver ratings.
- Generate actionable business insights.

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/yashtailor3009/Ola_Ride-Data-Analysis.git
```

Navigate to the application folder:

```bash
cd Ola_Ride-Data-Analysis/ola_ride_insights
```

Create and activate a virtual environment:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the Streamlit application:

```bash
streamlit run app.py
```

## 📈 Power BI Dashboard

The Power BI dashboard includes five analytical pages:

1. Overall Dashboard
2. Vehicle Analysis
3. Revenue Analysis
4. Cancellation Analysis
5. Rating Analysis

Interactive slicers, KPI cards, charts, and cross-page filtering help explore the data.

## 💡 Key Insights

- Approximately 62.09% of bookings become successful rides.
- Driver-side issues account for a significant share of failed bookings.
- Successful rides generated approximately ₹3.51 crore in revenue.
- Approximately ₹2.15 crore represents quoted fare value from unsuccessful bookings.
